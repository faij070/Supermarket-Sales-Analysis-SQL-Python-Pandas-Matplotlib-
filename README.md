# Supermarket-Sales-Analysis-SQL-Python-Pandas-Matplotlib-

## 📌 Project Overview

This project analyzes supermarket sales data to identify business trends, customer purchasing behavior, product performance, and payment preferences. The complete workflow includes data cleaning, SQL-based data preparation, exploratory data analysis using Python, and data visualization for business insights.

---

## 🎯 Project Objectives

- Clean and prepare raw sales data for analysis.
- Analyze sales performance across different product lines.
- Identify monthly sales trends.
- Understand customer payment preferences.
- Explore sales distribution and purchasing patterns.
- Generate actionable business insights through SQL and Python.

---

## 🛠️ Tools & Technologies

- **SQL** – Data Cleaning & Querying
- **Python**
  - Pandas
  - NumPy
  - Matplotlib
- **Jupyter Notebook**
- **Microsoft Excel**

---

## 📂 Project Workflow

### 1️⃣ Data Collection
- Imported supermarket sales dataset.
- Verified data quality and structure.

### 2️⃣ Data Cleaning (SQL)
- Removed duplicate records.
- Handled missing values.
- Corrected data types.
- Prepared data for analysis.

### 3️⃣ Exploratory Data Analysis (Python)
- Loaded cleaned dataset using Pandas.
- Performed descriptive statistics.
- Analyzed sales trends.
- Compared product line performance.
- Explored payment method distribution.

### 4️⃣ Data Visualization
Created visualizations using Matplotlib:

- 📊 Bar Chart – Total Sales by Product Line
- 📈 Line Chart – Monthly Sales Trend
- 🥧 Pie Chart – Sales Distribution by Payment Method
- 📉 Histogram – Distribution of Sales Amount

---

## 📊 Key Business Insights

- Identified the highest-performing product lines based on total sales.
- Analyzed monthly sales trends to understand business performance over time.
- Compared customer payment methods to identify the most preferred option.
- Examined transaction value distribution using a histogram.
- Generated insights that can support inventory planning and business decisions.
